# Tyrael Integration Desktop

Нативный Windows-клиент `Tyrael Integration Server`, которым пользуется и Telegram-бот. Приложение не запускает второй Codex/Claude и не читает Telegram-токен.

В первой версии доступны:

- общий каталог Codex- и Claude-задач;
- локальная история выбранной задачи с постраничной загрузкой ранних сообщений;
- локальные черновики отдельно для каждой задачи, переживающие закрытие и обновление приложения;
- текущая задача и все активные ходы;
- живые этапы, накопленный прогресс и формируемый ответ;
- переключение задачи без Telegram-уведомления;
- создание новой Codex- или Claude-задачи;
- отправка сообщения в свободную задачу через существующий Integration Server.

Последние десять обменов загружаются сразу; кнопка над диалогом добавляет по десять более ранних. Для Codex источником служит локальный thread/rollout, для Claude — локальный transcript; Telegram для чтения истории не используется. Текущий живой ответ отображается после уже загруженной истории и после завершения становится её обычной частью.

Неотправленный текст автоматически сохраняется в локальном `DesktopApp\drafts.json` через 600 мс после ввода, при переключении задачи и при закрытии окна. Черновики не передаются в Integration Server или Telegram и удаляются после успешной отправки соответствующего сообщения. Ошибка записи явно показывается в нижней строке приложения.

Если задача либо тот же Git-репозиторий занят, приложение безопасно откажется запускать параллельный ход. Управление очередью, подтверждениями и отменой остаётся в Telegram до следующего этапа.

## Сборка и установка

На Windows достаточно встроенного .NET Framework, загрузка SDK и внешних пакетов не требуется:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\install.ps1
```

Исполняемый файл устанавливается в `%LOCALAPPDATA%\Tyrael\TelegramIntegration\DesktopApp`, ярлык создаётся на рабочем столе. Сборка без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\build.ps1
```

Скомпилированный каталог `DesktopApp\dist` в Git не входит.
