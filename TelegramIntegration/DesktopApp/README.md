# Tyrael Integration Desktop

Нативный Windows-клиент `Tyrael Integration Server`. Telegram и Desktop используют один каталог задач, одни активные ходы и один набор настроек; приложение не запускает второй Codex/Claude и не читает Telegram-токен.

## Возможности

- поиск, выбор, создание, переименование и архивирование Codex/Claude-задач;
- локальная история, живой накопительный прогресс и текущий ответ;
- смена агента, модели, reasoning, Plan/Work, проекта и режима подтверждений;
- подтверждения, сохранённые сообщения/очередь, отмена хода, diff, статус, лимиты, TTS и безопасный рестарт;
- выделение текста ответа и добавление аннотации к следующему запросу;
- вставка скриншота через `Ctrl+V`, drag-and-drop и выбор до восьми изображений;
- локальные черновики отдельно для каждой задачи: текст, аннотации и изображения переживают переключение, закрытие и обновление клиента.
- выполняющийся через Integration Server ход отмечается `🤖`; внешние активные ходы сохраняют обычный индикатор.

Визуальная система сочетает cyan/mint Codex и amber/coral Claude на нейтральном тёмном фоне. Цвет провайдера используется как акцент состояния, а не как заливка всей карточки.

История и изображения читаются с локального компьютера. В Desktop API разрешены только изображения, предварительно скопированные клиентом в `%LOCALAPPDATA%\Tyrael\TelegramIntegration\DesktopApp\attachments`; путь, тип, количество и размер проверяются Integration Server.

Черновики хранятся в `DesktopApp\drafts-v2.json`, не передаются на сервер до отправки и мигрируют из прежнего `drafts.json`. После успешного запуска хода временные изображения удаляет Integration Server.

## Управление

- `Ctrl+Enter` — отправить;
- `Ctrl+V` — вставить изображение из буфера;
- выделить фрагмент ответа → правая кнопка → **Комментировать выделение**;
- изображения можно перетащить прямо в поле ввода.

## Сборка и установка

Новые SDK и пакеты не требуются: используется системный WPF/.NET Framework.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\install.ps1
```

Сборка без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\build.ps1
```

EXE устанавливается в `%LOCALAPPDATA%\Tyrael\TelegramIntegration\DesktopApp`, ярлык создаётся на рабочем столе. `DesktopApp\dist` в Git не входит.
