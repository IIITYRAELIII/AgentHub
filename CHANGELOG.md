# Agent Hub release notes

## 2.0.1 — Standalone source and Windows distribution

- `Автор`: `IIITYRAELIII` (GitHub UID `95281881`).
- `Компоненты`: `agent-hub`.
- `Для кого`: пользователи и разработчики Agent Hub.
- `Действие`: `optional`; установка и обновление используют версионный архив.
- `Контракты`: `REL-001`, `RST-001`, `MCP-001`, `PERF-001`, `UI-001`, `USG-001`.
- `Изменения`: сохранены исправления ответов после ротации, передачи файлов,
  облегчённого снимка доски и явного выбора проверок. Упаковка сохраняет
  сопутствующие C#-файлы; проверены адресные исправления SQLite и установщика.
  Публичные исходники отделены от приватных настроек, истории выполнения и
  сведений о согласиях. Нормальная установка не требует Git, npm или компилятора.
- [HUB-329](agent-hub://task/16343338-b3be-4703-82fb-0fd4ee1598e6 "Вынести Hub в отдельный репозиторий"):
  подготовлен штатный выпуск установочного архива через GitHub Release и явная
  регистрация первой публичной исходной точки. Неопределённый результат загрузки
  сохраняется до проверки внешнего эффекта. Опубликованная версия и история
  учитываются при обычном Test/Await без зависимости от удалённого каталога сборки.
  Эти изменения не объявляют архив опубликованным или установленным.
- `Проверка`: выполнены необходимые адресные проверки; полный набор пропущен
  по выбору владельца. Пропущенные проверки не считаются успешными.
- `Установка/обновление`: используйте архив, `install_release.py` и контрольные
  суммы одного GitHub Release; см. `AgentHub/distribution/INSTALL.md`.
- `Перезапуск`: установщик не запускает Hub; после установки применяется
  штатный запуск, после обновления — согласованное окно остановленных writers.

This draft retains the original Hub contract-governance boundary from the
private Utilities development history. It does not import unrelated Utilities
release notes or claim a standalone release. Current installation instructions
are in README.md; historical instructions below describe their original date.

## 2026-08-25 — Контракты Agent Hub фиксируют принятые решения

- `Автор`: `IIITYRAELIII` (GitHub UID `95281881`).
- `Компоненты`: `agent-hub`, `agent-hub-test-contour`.
- `Для кого`: разработчики и пользователи Agent Hub.
- `Действие`: `none`; реестр используется из текущего дерева Utilities.
- `Контракты`: `SYS-001`, `MSG-001`, `TURN-001`, `UI-001`, `RST-001`,
  `PERF-001`, `REL-001`.
- `Проверка`: выполнить `npm run contracts:check` в `AgentHub`; проверка должна
  подтвердить семь уникальных контрактов и доступность каждого документа.
- `Установка/обновление`: `use-in-place`.
- `Перезапуск`: не требуется; Test Contour обновляется автоматически.
- `Изменения`: добавлены машинный реестр принятых контрактов, ADR по единому
  durable command ledger и логическим ChangeSet, карта повторных инцидентов и
  обязательная проверка контрактов и новых Agent Hub changelog entries в общем
  syntax check. CLI выбирает контракты
  по изменяемым путям, roadmap задаёт проверяемые этапы миграции, а описание
  release registry отделяет необходимый coordination ledger от дефектной
  turn-scoped реализации. Контракты фиксируют
  неизменяемые identity/state/SLO-границы для задержек, дублей, финалов,
  mark-read, рестарта и релизов.
