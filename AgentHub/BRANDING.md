# Фирменный знак Agent Hub

Фирменный знак Agent Hub — три изогнутые ленты бирюзового, фиолетового и
кобальтового цветов вокруг круглого просвета. Геометрия, цвета и объём знака
зафиксированы в исходном мастер-файле
[`assets/mini-app/agent-hub-mark.png`](assets/mini-app/agent-hub-mark.png).

## Неизменяемая часть

- Темы не заменяют, не перекрашивают, не поворачивают и не обрезают знак.
- `.brand-mark` и `[data-app-mark]` принадлежат общей оболочке приложения.
  CSS, JS и HTML внутри пакета темы не должны обращаться к ним; реестр тем
  проверяет это при загрузке и отклоняет нарушающий пакет.
- Новый вариант знака вводится только после явного согласования с пользователем.
  После согласования сначала заменяется мастер-файл, затем из него заново
  создаются платформенные производные. Рисовать их независимо нельзя.

## Платформенные варианты

| Поверхность | Файл | Правило |
| --- | --- | --- |
| Web, Telegram и страница входа | `assets/mini-app/agent-hub-mark.png` | Прозрачный мастер без подложки |
| VS Code | `VSCodeExtension/media/agent-hub-mark.png` | Тот же знак для Activity Bar, Marketplace и webview |
| Windows | `DesktopApp/AgentHub.ico` | ICO, созданный из того же мастер-знака |
| Android launcher | `AndroidApp/app/src/main/res/drawable-nodpi/ic_agent_hub.png` | Тот же знак на тёмной безопасной подложке `#071116` |

Подложка и свободное поле Android-иконки — только адаптация под системные
круглые и скруглённые маски launcher. Это не другой логотип. Обычная и круглая
иконки в `AndroidManifest.xml` обязаны ссылаться на один ресурс
`@drawable/ic_agent_hub`.

## Проверка изменений

После изменений знака или механизма тем выполните из каталога `AgentHub`:

```powershell
node --test tests/public/theme-registry.test.mjs
node --test VSCodeExtension/render.test.js
```

Дополнительно проверьте визуально мастер на прозрачном фоне, Windows ICO и
Android launcher icon при малом размере и под круглой маской.
