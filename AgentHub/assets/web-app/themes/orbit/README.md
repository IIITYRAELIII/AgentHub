# Орбита

Тема превращает Agent Hub в единый центр орбитального наблюдения. Ночная Земля,
трассы спутников, полярное сияние и лунный горизонт проходят под полупрозрачной
рабочей поверхностью, поэтому интерфейс занимает почти весь экран и не повторяет
разнесённую компоновку Verdant. Координатные шкалы из «Картографии» удалены, чтобы
они не образовывали отдельную яркую рейку вдоль края интерфейса.

Знак `orbit-mark.png` взят непосредственно из согласованного концепта.
Единственный живой эффект — редкий маркер сопровождения, который меняет только
`transform` и `opacity`; при `prefers-reduced-motion` он отключается.
