# Verdant

Холодная зелёная тема о природе, поглотившей древнюю инфраструктуру. Визуальный
центр сцены — заросшие коммуникационные башни; интерфейс использует тёмное
минеральное стекло, почти прямые углы и тонкий сигнальный акцент.

Единственный движущийся эффект — редкий полноэкранный сканирующий импульс. Он
анимирует только `transform`, отключается через `prefers-reduced-motion` и не
использует JavaScript, canvas, WebGL или анимированное размытие. Карточки чата и
журнала намеренно не применяют `backdrop-filter`, чтобы длинные истории не
создавали сотни отдельных compositor-слоёв.
