# Verdant

Холодная зелёная тема о природе, поглотившей древнюю инфраструктуру. Визуальный
центр сцены — заросшие коммуникационные башни; интерфейс использует тёмное
минеральное стекло, почти прямые углы и тонкий сигнальный акцент.

На широком экране список задач и чат становятся двумя отдельными полевыми
консолями: между панелями есть зазор, а справа остаётся открытой значительная
часть окружения. Сообщения агента лежат прямо на стекле, пользовательские ответы
остаются компактными терминальными пластинами. Стекло намеренно прозрачное, а
короткие световые риски выделяют все четыре угла панели, как в исходном
концепте; мобильная компоновка не меняется.

В теме три сцены: штормовые кольцевые руины, залитая утренним светом долина с
монолитами и тёмное машинное святилище в мокром лесу. Все три сохраняют один
сканирующий импульс и отдельное кадрирование для узкого экрана.

Единственный движущийся эффект — редкий полноэкранный сканирующий импульс. Он
анимирует только `transform`, отключается через `prefers-reduced-motion` и не
использует JavaScript, canvas, WebGL или анимированное размытие. Карточки чата и
журнала намеренно не применяют `backdrop-filter`, чтобы длинные истории не
создавали сотни отдельных compositor-слоёв.
