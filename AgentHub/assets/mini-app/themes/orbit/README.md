# Орбита

Тема превращает Agent Hub в единый центр орбитального наблюдения. Ночная Земля,
координатные шкалы и трассы спутников проходят под полупрозрачной рабочей
поверхностью, поэтому интерфейс занимает почти весь экран и не повторяет
разнесённую компоновку Verdant.

Знак `orbit-mark.png` взят непосредственно из согласованного концепта.
Единственный живой эффект — редкий маркер сопровождения, который меняет только
`transform` и `opacity`; при `prefers-reduced-motion` он отключается.
