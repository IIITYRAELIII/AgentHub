    Как считается расход

    ПТЭ — приведённые токен-эквиваленты. База = входные токены + кэшированный вход × 0,1 + выходные токены × 6 + токены рассуждений × 6;

    • GPT-5.4 и GPT-5.6-Terra — База;
    • GPT-5.5 и GPT-5.6-Sol — База ×2;
    • GPT-5.4-mini — База ×0,3;
    • GPT-5.6-Luna — База ×0,4;
    • режим Fast дополнительно увеличивает расход в 2,5 раза для GPT-5.5 и всех GPT-5.6 и в 2 раза для GPT-5.4; на GPT-5.4-mini не влияет;
    • Codex Spark в общем расходе не учитывается — у него отдельный лимит.

    cr — официальные «кредиты» Codex, ПТЭ / 16000.

    $ — эквивалентная цена токенов по ключу API, cr / 25.

    ₽ — доллары по официальному курсу ЦБ РФ.

    У задач Claude базой служит цена API Anthropic за те же токены; в cr она переводится тем же курсом 25 cr = $1.
