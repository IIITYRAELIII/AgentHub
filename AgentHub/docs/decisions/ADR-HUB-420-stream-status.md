# Stream status and explicit read actions

Accepted for UI-001.

The activity heading exposes manual acknowledgement of ready responses. The
client selects exact final identities from the current snapshot and uses the
existing read operation and receipt projection. Rendered-history evidence
remains the prerequisite for automatic acknowledgement.

A turn with verified inter-Stream origin uses a dotted indicator until the first
ordinary user contribution reaches that turn. Its final carries the same
classification. A missing origin uses ordinary presentation. The two motion
settings preserve concurrent status indicators and honor reduced motion.
