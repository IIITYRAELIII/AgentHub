# Agent Hub Desktop

Нативный Windows-клиент `Agent Hub Server`. Telegram и Desktop используют один каталог задач, одни активные ходы и один набор настроек; приложение не запускает второй Codex/Claude и не читает Telegram-токен.

## Возможности

- поиск, выбор, создание, переименование и архивирование Codex/Claude-задач;
- локальная история, живой накопительный прогресс и текущий ответ;
- смена агента, модели, reasoning, Plan/Work, проекта и режима подтверждений;
- подтверждения, сохранённые сообщения/очередь, отмена хода, diff, статус, лимиты, TTS и безопасный рестарт;
- накопление нескольких цитат из ответов с отдельными комментариями к следующему запросу;
- вставка через `Ctrl+V`, drag-and-drop и выбор до восьми файлов или изображений;
- миниатюры изображений, возвращённых Codex через `generatedImage` или `image` после `view_image`, с открытием во встроенном просмотрщике;
- ссылки на существующие файлы внутри выбранного проекта открываются в VS Code; при
  наличии в Markdown суффикса `:строка` курсор переходит к этой строке;
- локальные черновики отдельно для каждой задачи: текст, аннотации и изображения переживают переключение, закрытие и обновление клиента.
- выполняющийся через Agent Hub Server ход отмечается `⚡`; внешние активные ходы сохраняют обычный индикатор.
- необработанные исключения WPF-host передаются в настроенную на сервере Sentry-диагностику без исходного текста ошибки, данных чата и вложений.

Визуальная система сочетает cyan/mint Codex и amber/coral Claude на нейтральном тёмном фоне. Цвет провайдера используется как акцент состояния, а не как заливка всей карточки.

EXE, окно и ярлык используют единый знак Agent Hub из трёх цветных стеклянных
лент; он совпадает со знаком общей Web-оболочки и не зависит от выбранной темы.

История и вложения читаются с локального компьютера. Desktop-клиент сразу копирует файлы, включая полученные через RDP-буфер обмена, в `%LOCALAPPDATA%\AgentHub\DesktopApp\attachments`; Agent Hub Server проверяет путь, количество и размер. Поэтому сообщение использует стабильную локальную копию, а не временный или RDP-путь источника.

Черновики хранятся в `DesktopApp\drafts-v2.json`, не передаются на сервер до отправки и мигрируют из прежнего `drafts.json`. После успешного запуска хода временные изображения удаляет Agent Hub Server.

## Управление

- `Ctrl+Enter` — отправить;
- `Ctrl+V` — вставить файл, несколько файлов или изображение из буфера;
- выделить фрагмент ответа → **Цитировать выделение**; повторить для следующих
  фрагментов, затем при необходимости дописать комментарий под каждой цитатой;
- файлы можно перетащить прямо в поле ввода.

## Сборка и установка

Новые SDK и пакеты не требуются: используется системный WPF/.NET Framework.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\install.ps1
```

Сборка без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DesktopApp\build.ps1
```

EXE `AgentHub.exe` устанавливается в runtime-каталог `%LOCALAPPDATA%\AgentHub\DesktopApp`, ярлык `Agent Hub` создаётся на рабочем столе. `DesktopApp\dist` в Git не входит.
