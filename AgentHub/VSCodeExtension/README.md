# Agent Hub

Командное VS Code-расширение Agent Hub для задач, чата и журнала работ.
Технический id расширения — `agent-hub.agent-hub`, внутренние идентификаторы
представлений и команд используют префикс `agentHub.*`.

- добавляет кнопку `Agent Hub` в Activity Bar;
- открывает общий интерфейс Agent Hub: задачи слева, чат справа и журнал отдельной вкладкой;
- подключается к локальному Agent Hub Server через аутентифицированный named pipe;
- поддерживает историю и живой ход, отправку, вставку изображений, аннотации,
  настройки задачи, подтверждения, очередь, остановку, diff, статус и рестарт;
- переход из задачи или хода журнала открывает соответствующий чат;
- автоматически перечитывает журнал после изменения, создания или атомарной замены файла;
- загружает пять последних дней сразу, старые дни и тела ходов — по запросу;
- сохраняет прокрутку и выбранное пользователем состояние раскрытых блоков
  при обновлении и пересоздании webview;
- показывает в закреплённой шапке кнопку `Свернуть всё`;
- переносит свежие лимиты Codex в ту же закреплённую шапку;
- в раскрытом списке старых ходов показывает кнопку `Свернуть ходы` под
  расходом задачи;
- использует оболочку Mini App и растровые фоны из активного неизменяемого
  runtime-релиза Agent Hub; открытый workspace не может подменить исполняемый
  код или оформление webview; панель использует тот же десктопный профиль
  интерфейса, что Telegram Desktop и Telegram Web;
- в заголовке панели доступен тот же автоматически найденный каталог тем, что и
  в Mini App; выбранная тема сохраняется локально в состоянии webview. `Storm`
  оживляет сцену шейдером: вода дышит, облака плывут, поверх льёт ливень,
  а редкий разряд подсвечивает кадр вторым снимком той же сцены. Сцена
  выбирается списком `Фон` только из вариантов текущей темы; у «Озера» три кадра одного
  вечера: съёмка, акварель и масло;
- панель намеренно остаётся тёмной независимо от темы VS Code;
- CSS, эффекты и изображения тем загружаются из самодостаточных пакетов активного
  runtime в `assets/mini-app/themes`; расширение не содержит отдельного реестра,
  поэтому добавление темы описано только в
  [общей инструкции](../assets/mini-app/themes/README.md);
- в боковой панели есть кнопки открытия и принудительного обновления журнала.

`shared-webview.js` берёт HTML/CSS/JS и фоны из текущего runtime-релиза, а
`vscode-bootstrap.js` и `agent-hub-bridge.js` остаются тонким VS Code-мостом без
передачи секрета в webview. После обновления только интерфейса достаточно
переоткрыть панель или выполнить `Обновить Agent Hub`; `Developer: Reload Window`
нужен лишь после изменения самого кода расширения-моста. Сборка:
`npx @vscode/vsce package`, установка: `code --install-extension
agent-hub-<версия>.vsix --force`.

Исходники входят в общий `Utilities/AgentHub`. Для установки без сборки VSIX
выполните из корня workspace:

```text
python Utilities/AgentHub/install.py
```

Установщик копирует расширение в профиль текущего пользователя VS Code.
Журнал и исходные rollout остаются локальными и в репозиторий не попадают.
