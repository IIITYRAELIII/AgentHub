# Agent HUB Work log

Командное VS Code-расширение Agent Hub для закреплённого журнала работ.

- добавляет кнопку `Agent HUB Work log` в Activity Bar;
- открывает корневой `WORK_LOG.md` закреплённой вкладкой в основной области редактора;
- автоматически перечитывает журнал после изменения, создания или атомарной замены файла;
- сохраняет прокрутку и выбранное пользователем состояние раскрытых блоков
  при обновлении и пересоздании webview;
- показывает в закреплённой шапке кнопку `Свернуть всё`;
- переносит свежие лимиты Codex в ту же закреплённую шапку;
- в раскрытом списке старых ходов показывает кнопку `Свернуть ходы` под
  расходом задачи;
- использует `Utilities/AgentHub/work-log.css`, оформление Mini App
  `Utilities/AgentHub/assets/mini-app/styles.css` и растровые фоны тем из той же
  папки; панель использует тот же десктопный профиль интерфейса, что Telegram
  Desktop и Telegram Web;
- в заголовке панели доступен тот же выбор тем: `Орбита`, `Туманность`,
  `Пульсар`, `Gothic`, `BlackHole`, `Тайга`, `Магма` и `Гроза`; выбранная тема
  сохраняется локально в состоянии webview;
- панель намеренно остаётся тёмной независимо от темы VS Code;
- в боковой панели есть кнопки открытия и принудительного обновления журнала.

Разметка и стили webview вынесены в `webview.js`, поэтому их можно отрисовать
без запуска VS Code. Сборка: `npx @vscode/vsce package`, установка:
`code --install-extension work-log-view-<версия>.vsix --force` и перезагрузка окна.

Исходники входят в общий `Utilities/AgentHub`. Для установки без сборки VSIX
выполните из корня workspace:

```text
python Utilities/AgentHub/install.py --profile journal
```

Установщик копирует расширение в профиль текущего пользователя VS Code.
Журнал и исходные rollout остаются локальными и в репозиторий не попадают.
