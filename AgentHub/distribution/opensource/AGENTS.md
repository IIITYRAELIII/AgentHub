# Agent Hub source repository

The application and its tests live in `AgentHub/`. Read
`AgentHub/AGENTS.md` and its accepted contracts before changing behavior.
Run development and validation commands from that directory. This repository
does not contain personal runtime data or the rest of Utilities.

Keep generated packages, dependencies, credentials, conversations and screenshots
of user data out of Git. Preserve source attribution and third-party notices.
Root `CHANGELOG.md` is release-owner metadata; Task work does not independently
rewrite it. Original Utilities receipts and frozen operations remain under their
original identity and are never retargeted to rewritten source OIDs.

Ready-package creation does not authorize deployment or provider effects. The
existing release owner controls accepted selection, publication and runtime
cutover. See `AgentHub/distribution/README.md` for the migration boundary.
